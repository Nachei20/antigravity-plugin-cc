# Adversarial Prompt Blocks for Antigravity

Use these targeted focus phrases with `/antigravity:adversarial-review` for deep, domain-specific audits:

## 1. Concurrency & Race Conditions
> `cuestiona si la sincronización de estados compartidos o accesos a recursos puede provocar deadlocks o condiciones de carrera bajo alta concurrencia`

## 2. Data Integrity & Transactions
> `evalúa si las operaciones de base de datos garantizan aislamiento ACID y qué sucede ante una falla a mitad de la transacción (estrategia de rollback)`

## 3. Error Handling & Edge Cases
> `identifica qué entradas malformadas, fallos de red o timeouts de servicios externos podrían hacer colapsar este componente`

## 4. Security & Authentication
> `audita la superficie de ataque, validación de permisos, inyección de dependencias y exposición de datos sensibles en logs o respuestas de error`
